🧬

Población

Conjunto de soluciones posibles (individuos). Cada individuo representa una posible selección de jugadores para el equipo. En este problema, una población de 30 individuos significa 30 posibles equipos distintos.

🔢

Cromosoma

Representación de una solución. Aquí cada cromosoma es un arreglo de bits donde 1 = jugador seleccionado y 0 = no seleccionado. Ejemplo: [1,0,1,1,0,0,1,0,0,1,1,0] indica qué jugadores forman el equipo.

📊

Fitness (Aptitud)

Mide qué tan buena es una solución. Se calcula sumando los atributos (velocidad, resistencia, ofensiva, defensa, equipo, experiencia) de los jugadores seleccionados y penalizando tamaños incorrectos del equipo.

🎯

Selección

Proceso de elegir padres para reproducirse. Torneo: se comparan k individuos al azar y el de mayor fitness gana. Ruleta: la probabilidad de selección es proporcional al fitness relativo de cada individuo.

✂️

Crossover (Cruce)

Combina dos cromosomas padres para generar hijos. Se elige un punto de corte aleatorio: el hijo 1 toma los genes del padre 1 hasta el corte y del padre 2 desde el corte. Así se heredan rasgos de ambas soluciones.

P1: 1 0 1 1 0 1
P2: 0 1 0 0 1 0
H1: 1 0 0 0 1 0
🎲

Mutación

Introduce variaciones aleatorias en el cromosoma hijo. Con una pequeña probabilidad, un bit cambia de 0 a 1 o viceversa. Esto evita que el algoritmo quede atrapado en óptimos locales y mantiene la diversidad genética.

🔄

Ciclo del Algoritmo Genético

1. Inicializar población aleatoria
↓
2. Evaluar fitness de cada individuo
↓
3. Seleccionar padres
↓
4. Aplicar Crossover → Nuevos hijos
↓
5. Aplicar Mutación
↓
6. Reemplazar población
↓
7. ¿Criterio de parada? → Si no: volver al paso 2
